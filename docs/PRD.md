# PRD: Astro-Karuta

## 概要
天文知識を「かるた」形式で学ぶ子ども向け天文教育ゲームアプリ。88星座・太陽系の惑星・有名な天文現象を題材にした読み札と絵札をデジタルかるたとして対戦プレイできる。

## 背景・課題
- 天文学の学習は教科書ベースで退屈になりがち
- 子どもが楽しみながら天文知識を身につける手段が限られている
- 日本の伝統的な「かるた」遊びとの親和性が高い

## ターゲットユーザー
- 小学生〜中学生（6-15歳）
- 天文に興味のある親子
- 理科教育に取り組む教育者

## MVP機能

### F1: デジタルかるた対戦（オンラインマルチプレイ）
- 88星座 + 太陽系天体の読み札・絵札データ
- WebSocket によるリアルタイム対戦
- マッチメイキング（ランダム/ルーム招待）
- 読み上げ音声（Web Audio API）
- ターン管理：読み札表示 → 絵札タップで取得判定

**受け入れ条件:**
- 2人対戦が正常に動作する
- 取り札判定は先着順（サーバーサイドでタイムスタンプ比較）
- 対戦中に切断した場合、30秒以内に再接続できる
- 全札消化または制限時間到達でゲーム終了

### F2: 天体コレクション
- 取得した札に対応する天体の詳細解説カードをコレクションに追加
- カード情報：名称、画像、等級、距離、可視時期、解説テキスト
- コレクション一覧表示、フィルタリング（星座/惑星/現象）

**受け入れ条件:**
- かるた対戦で取得した札のみコレクションに追加される
- コレクション進捗率が表示される（取得数/全数）
- カード詳細画面に天体解説が表示される

### F3: 季節連動デッキ・観測ミッション
- 現在の日付と緯度経度から「今夜見える星座」を算出
- 季節限定デッキが自動更新される
- 観測ミッション：指定天体を「実際に見た」と報告するとボーナスカード獲得

**受け入れ条件:**
- 季節デッキが月ごとに自動更新される
- 観測ミッションは位置情報 + 時刻で簡易検証
- ボーナスカードがコレクションに追加される

## 技術スタック
| レイヤー | 技術 |
|---------|------|
| Frontend | TypeScript, Next.js (PWA), Web Audio API |
| Real-time | WebSocket |
| Backend | Go |
| Database | PostgreSQL |
| Cache | Redis |
| Infra | GCP Cloud Run, Cloud Storage |

## 非機能要件
- WebSocket 接続の遅延: < 100ms（同一リージョン）
- 対戦マッチング: < 5秒
- PWA オフライン: コレクション閲覧はオフラインで可能
- レスポンシブ: モバイルファースト

## 対象外（v1.0）
- AI対戦（CPU対戦）
- ランキング・リーダーボード
- 課金・アプリ内購入
- ネイティブアプリ（PWAで対応）
